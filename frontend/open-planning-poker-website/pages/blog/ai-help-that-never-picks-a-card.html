AI help in planning poker that never picks a card

An estimate is a team's shared understanding, so a model should not make it. What a model can do well is ask the questions the team forgot and write the note nobody wants to write.

Three small jobs

  • Check the ticket before voting: up to three short points such as missing acceptance criteria or open questions. Everyone in the room sees them.
  • Ideas to split after a reveal with the top card or many "?" votes: two to four smaller tickets, each can be added to the game with one click.
  • Summarize the discussion after the final estimate: one sentence from the voters' notes and the chat since the reveal. The host edits it, and it goes into the Jira comment and the PDF report.

The rules it follows

  • It never suggests a card, a number of points or hours.
  • Only the ticket title and description, the notes and the chat lines are sent; player names are replaced with "a player" first.
  • It is off unless the server operator adds an API key, and then off in every room until the host turns it on.

Self-hosting? Set Ai__ApiKey on the game engine to turn it on for your server.
