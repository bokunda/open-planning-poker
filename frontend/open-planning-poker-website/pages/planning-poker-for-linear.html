Planning poker for Linear

Estimate your Linear backlog together. Import the issues, vote with hidden cards, reveal at once and write the agreed estimate back to Linear in one click.

How to run planning poker with Linear

  1. Connect Linear: The host connects Linear once from the import dialog. Players never need an account.
  2. Import the issues: Choose issues from a team's active cycle or its open issues. Each issue becomes a ticket with its link and description.
  3. Vote and reveal: Everyone picks a card in secret. The host reveals, and the room shows the spread, the average and the notes of the lowest and highest voters.
  4. Save the estimate: After the reveal, save the agreed card to the issue's estimate (whole numbers) with one click, or save all estimates of the session at once.

Sort a long backlog first

With many issues, start with the sorting board: players drag issues onto card columns in silence, and only the ones they disagree on get a full vote. All estimates are then saved to Linear together.

What is stored

The connection token is stored encrypted on the server and never reaches the browser. Disconnecting deletes it. Read the privacy policy for details.

Questions

Is the Linear integration free?

Yes. Every integration of Open Planning Poker is free, including import and saving estimates back.

Do players need a Linear account?

No. Only the host connects Linear; players join the room with a link.
