Privacy policy

Open Planning Poker is built to need as little data as possible. There are no accounts, no passwords and no ads. The code is open, so you can check everything below.

Who runs it

openplanningpoker.com and app.openplanningpoker.com are run by Bojan Piskulic (Bitcrafta). Contact: open an issue on GitHub.

What we store

  • Usernames: random by default or the name you type. Deleted 24 hours after they are created.
  • Games, tickets, votes and notes: kept in our database so teams can see past estimates, team rooms and reports. A host can delete a game at any time.
  • Chat: the last 100 messages per game, deleted after 24 hours.
  • Reactions: sent to the room and never stored.
  • We do not store email addresses, passwords or payment details.

Integrations

  • Slack: we store the workspace's bot token (encrypted) to post the room and the results. We read only the text of the /poker command. We do not read messages.
  • Microsoft Teams: the tab is our web app inside Teams. We store which game a tab shows. We do not access Teams data.
  • Jira Cloud: we store the access tokens of the person who connected Jira (encrypted). We read the issues you import and write the estimate and an optional comment when you click Save. Disconnecting deletes the tokens.

Analytics

We use Google Analytics and Microsoft Clarity on the website and the app to see which pages and features are used. They do not see ticket names, votes or chat.

Our own server also counts, without cookies, how often each website page is opened and how many rooms are created from it. Only the name of the page is counted: no IP address, no user id.

Where the data is

Our servers are at Hetzner in Germany (EU). Backups are encrypted and kept for 14 days.

Your choices

You can use Open Planning Poker without any integration. To have a game or a connection removed, delete it in the app or ask us on GitHub.
