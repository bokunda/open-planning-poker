Javni API i webhookovi

Svaka timska soba ima mali API samo za čitanje i odlazne webhookove. Iskoristi ih za svoje izveštaje, za povezivanje alata koji još ne podržavamo ili za vežbanje integracija na pravom API-ju.

Autentikacija

Vlasnik tima pravi token u timskoj sobi pod API i webhookovi. Prikazuje se jednom; čuvamo samo njegov hash. Šalji ga kao bearer token. Token čita samo svoj tim, a vlasnik može da ga opozove u bilo kom trenutku.

curl -H "Authorization: Bearer opp_…" https://ge.openplanningpoker.com/api/v1/sessions?take=10

Ograničenja

60 zahteva u minuti po tokenu, uz uobičajeno ograničenje po adresi. Iznad toga API odgovara sa 429 i Retry-After: 60. Liste se straniče sa skip i take (najviše 100).

Endpointi

  • GET /api/v1/team: Naziv i opis tima.
  • GET /api/v1/sessions: Sesije planiranja (sprintovi), najnovije prve, sa poenima i tokom svake sesije.
  • GET /api/v1/sessions/{id}/tickets: Tiketi sesije sa dogovorenom procenom i linkom ka alatu za tikete.

API nikad ne vraća pojedinačne glasove ni imena igrača: samo brojke koje timska soba već prikazuje.

Greške su JSON: {"error": {"code": "unauthorized", "message": "…"}} sa statusom 401, 404 ili 429.

Webhookovi

Dodaj https adresu i izaberi događaje. ticket.estimated stiže kad tiket dobije konačnu procenu (changed je true kad je procena izmenjena). session.finished stiže kad poslednji otvoreni tiket sesije dobije procenu.

POST https://your-endpoint.example.com/opp
X-OPP-Event: ticket.estimated
X-OPP-Delivery: 5f0c…            (the same on every retry of this event)
X-OPP-Signature: t=1795291800,v1=9c1d…

{
  "id": "5f0c…", "type": "ticket.estimated", "createdAt": "2026-11-21T20:10:00Z", "teamId": "…",
  "data": {
    "sessionId": "…", "sessionName": "Sprint 12",
    "ticket": { "id": "…", "name": "Login with SSO", "externalKey": "PAY-42", "externalUrl": "…", "estimate": "5" },
    "changed": false
  }
}
{ "type": "session.finished", "data": { "sessionId": "…", "sessionName": "Sprint 12", "ticketCount": 14, "points": 41 } }

Odgovori bilo kojim 2xx u roku od 10 sekundi. Neuspele isporuke se ponavljaju posle 1, 5 i 30 minuta; poslednjih 20 isporuka se vidi u timskoj sobi. Koristi X-OPP-Delivery da odbaciš duplikate. Interne adrese se odbijaju.

Proveri potpis

X-OPP-Signature je t=<unix vreme>,v1=<HMAC-SHA256 od "t.body"> sa tajnom tvog webhooka. Odbaci zahteve čije vreme odstupa više od pet minuta.

import crypto from 'node:crypto';

// body: the raw request body as a string, header: the X-OPP-Signature value
export function verify(secret, header, body, toleranceSeconds = 300) {
  const parts = Object.fromEntries(header.split(',').map((p) => p.split('=')));
  if (Math.abs(Date.now() / 1000 - Number(parts.t)) > toleranceSeconds) return false;
  const expected = crypto.createHmac('sha256', secret).update(`${parts.t}.${body}`).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(parts.v1 ?? ''));
}
import hashlib, hmac, time

def verify(secret: str, header: str, body: str, tolerance: int = 300) -> bool:
    parts = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(parts["t"])) > tolerance:
        return False
    expected = hmac.new(secret.encode(), f"{parts['t']}.{body}".encode(), hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts.get("v1", ""))

Zapier i n8n

Pitanja

Da li je API besplatan?

Da. API i webhookovi su deo svake timske sobe, bez plaćenog plana.

Mogu li da upisujem podatke preko API-ja?

Još ne: javni API je samo za čitanje. Procene upisuje sama aplikacija, koja može da ih sačuva u Jiru, GitHub, Linear ili Azure DevOps.
