Pravi svoje aplikacije na Open Planning Poker API-ju

Svaka timska soba sada ima mali API samo za čitanje i potpisane webhookove. Besplatni su, dokumentovani i pravi, pa su dobro mesto da napraviš svoje alate ili vežbaš integracije.

Šta možeš da napraviš

  • Sopstveni dashboard brzine u tabeli, Grafani ili na statičnoj stranici, iz /api/v1/sessions.
  • Most ka alatu koji još ne podržavamo: osluškuj ticket.estimated i upiši procenu tamo gde tim drži posao.
  • Obaveštenja u chatu na Discordu, Mattermostu ili Matrixu kad se sesija završi.
  • Projekat za učenje: API sa tokenima, straničenjem, ograničenjima i potpisanim webhookovima je realna vežba za studente i juniore.

Kreni za pet minuta

  1. Otvori timsku sobu i, kao vlasnik, napravi token pod API i webhookovi.
  2. Pozovi API:
curl -H "Authorization: Bearer opp_…" https://ge.openplanningpoker.com/api/v1/sessions?take=5

Dobijaš sesije tima sa poenima, slaganjem u prvom glasanju i ponovnim glasanjima, straničeno sa skip i take. Tiketi sesije stižu sa /api/v1/sessions/{id}/tickets, sa dogovorenim procenama i linkovima ka alatu. API nikad ne vraća pojedinačne glasove ni imena igrača.

Vežbaj webhookove kako treba

Dodaj adresu webhooka i za svaku procenu dobijaš potpisan JSON. Mali prijemnik u Nodu pokazuje ceo obrazac: pročitaj sirovo telo, proveri potpis, pa obradi događaj.

import http from 'node:http';
import { verify } from './verify.js'; // the check from the API docs

http.createServer((req, res) => {
  let body = '';
  req.on('data', (chunk) => (body += chunk));
  req.on('end', () => {
    if (!verify(process.env.OPP_WEBHOOK_SECRET, req.headers['x-opp-signature'] ?? '', body)) {
      res.writeHead(401).end();
      return;
    }
    const event = JSON.parse(body);
    if (event.type === 'ticket.estimated') {
      console.log(`${event.data.ticket.externalKey ?? event.data.ticket.name}: ${event.data.ticket.estimate}`);
    }
    res.writeHead(204).end();
  });
}).listen(3000);

Vredi vežbati: odbijanje zahteva sa pogrešnim ili starim potpisom, odbacivanje duplikata pomoću X-OPP-Delivery, brz odgovor uz kasniji spori posao, i praćenje ponovnih pokušaja u listi isporuka kad prijemnik vrati grešku.

Ograničenja i fer korišćenje

60 zahteva u minuti po tokenu, uz uobičajeno ograničenje po adresi. Iznad toga dobijaš 429 sa Retry-After. Webhookovi idu samo na javne https adrese.

Sve ostalo je u dokumentaciji API-ja: endpointi, događaji, provera potpisa u Nodu i Pythonu, i koraci za n8n i Zapier.
