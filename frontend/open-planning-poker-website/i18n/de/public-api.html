Öffentliche API und Webhooks

Jeder Team-Raum hat eine kleine API zum Lesen und ausgehende Webhooks. Nutze sie für eigene Berichte, um ein Tool anzubinden, das wir noch nicht unterstützen, oder um Integrationen an einer echten API zu üben.

Authentifizierung

Der Inhaber des Teams erstellt im Team-Raum unter API und Webhooks ein Token. Es wird einmal angezeigt; wir speichern nur seinen Hash. Sende es als Bearer-Token. Ein Token liest nur sein eigenes Team, und der Inhaber kann es jederzeit widerrufen.

curl -H "Authorization: Bearer opp_…" https://ge.openplanningpoker.com/api/v1/sessions?take=10

Grenzen

60 Anfragen pro Minute und Token, dazu die übliche Grenze pro Adresse. Darüber antwortet die API mit 429 und Retry-After: 60. Listen sind mit skip und take (bis 100) seitenweise.

Endpunkte

  • GET /api/v1/team: Name und Beschreibung des Teams.
  • GET /api/v1/sessions: Die Planungssitzungen (Sprints), die neuesten zuerst, mit Punkten und dem Verlauf jeder Sitzung.
  • GET /api/v1/sessions/{id}/tickets: Die Tickets einer Sitzung mit der vereinbarten Schätzung und dem Link zum Tracker.

Die API liefert nie einzelne Stimmen oder Spielernamen: nur die Zahlen, die der Team-Raum ohnehin zeigt.

Fehler sind JSON: {"error": {"code": "unauthorized", "message": "…"}} mit Status 401, 404 oder 429.

Webhooks

Füge eine https-Adresse hinzu und wähle die Ereignisse. ticket.estimated kommt, wenn ein Ticket eine endgültige Schätzung bekommt (changed ist true, wenn eine Schätzung geändert wurde). session.finished kommt, wenn das letzte offene Ticket einer Sitzung eine bekommt.

POST https://your-endpoint.example.com/opp
X-OPP-Event: ticket.estimated
X-OPP-Delivery: 5f0c…            (the same on every retry of this event)
X-OPP-Signature: t=1795291800,v1=9c1d…

{
  "id": "5f0c…", "type": "ticket.estimated", "createdAt": "2026-11-21T20:10:00Z", "teamId": "…",
  "data": {
    "sessionId": "…", "sessionName": "Sprint 12",
    "ticket": { "id": "…", "name": "Login with SSO", "externalKey": "PAY-42", "externalUrl": "…", "estimate": "5" },
    "changed": false
  }
}
{ "type": "session.finished", "data": { "sessionId": "…", "sessionName": "Sprint 12", "ticketCount": 14, "points": 41 } }

Antworte innerhalb von 10 Sekunden mit einem 2xx. Fehlgeschlagene Zustellungen werden nach 1, 5 und 30 Minuten wiederholt; die letzten 20 stehen im Team-Raum. Nutze X-OPP-Delivery, um Duplikate zu verwerfen. Interne Adressen werden abgelehnt.

Signatur prüfen

X-OPP-Signature ist t=<Unix-Zeit>,v1=<HMAC-SHA256 von "t.body"> mit dem Secret deines Webhooks. Lehne Anfragen ab, deren Zeit mehr als fünf Minuten abweicht.

import crypto from 'node:crypto';

// body: the raw request body as a string, header: the X-OPP-Signature value
export function verify(secret, header, body, toleranceSeconds = 300) {
  const parts = Object.fromEntries(header.split(',').map((p) => p.split('=')));
  if (Math.abs(Date.now() / 1000 - Number(parts.t)) > toleranceSeconds) return false;
  const expected = crypto.createHmac('sha256', secret).update(`${parts.t}.${body}`).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(parts.v1 ?? ''));
}
import hashlib, hmac, time

def verify(secret: str, header: str, body: str, tolerance: int = 300) -> bool:
    parts = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(parts["t"])) > tolerance:
        return False
    expected = hmac.new(secret.encode(), f"{parts['t']}.{body}".encode(), hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts.get("v1", ""))

Zapier und n8n

n8n: Füge einen Webhook-Knoten (POST) hinzu, kopiere seine Produktions-URL in den Team-Raum, dann einen Code-Knoten mit der Prüfung oben, und leite die Schätzung an Slack, eine Tabelle oder deinen Tracker weiter. Zapier: Nutze Webhooks by Zapier → Catch Raw Hook als Auslöser, damit der Body unverändert bleibt, dann einen Schritt Code by Zapier für die Prüfung. Zum regelmäßigen Lesen nimm einen HTTP-Knoten oder Webhooks by Zapier → GET mit dem Header Authorization.

Fragen

Ist die API kostenlos?

Ja. API und Webhooks gehören zu jedem Team-Raum, ohne bezahlten Plan.

Kann ich über die API Daten schreiben?

Noch nicht: Die öffentliche API ist nur zum Lesen. Schätzungen schreibt die App selbst, die sie in Jira, GitHub, Linear oder Azure DevOps speichern kann.
