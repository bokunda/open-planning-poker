Planning Poker für Jira

Schätzt euer Jira-Backlog gemeinsam. Importiere die Issues, stimmt mit verdeckten Karten ab, deckt gleichzeitig auf und schreibt die vereinbarte Schätzung mit einem Klick zurück nach Jira.

So läuft Planning Poker mit Jira

  1. Jira verbinden: Der Host verbindet Jira einmal im Import-Dialog. Spieler brauchen nie ein Konto.
  2. Issues importieren: Wähle Issues aus einem Sprint, einem Board oder einer JQL-Abfrage. Jedes Issue wird ein Ticket mit Link und Beschreibung.
  3. Abstimmen und aufdecken: Alle wählen geheim eine Karte. Der Host deckt auf, und der Raum zeigt die Streuung, den Durchschnitt und die Notizen der niedrigsten und höchsten Stimme.
  4. Schätzung speichern: Nach dem Aufdecken speicherst du die vereinbarte Karte mit einem Klick in Story Points, oder alle Schätzungen der Sitzung auf einmal.

Auch den Sprint planen

Im Team-Raum trägst du die Tage jedes Mitglieds ein, bekommst ein Punkte-Budget aus vergangenen Sprints und wählst die passenden Issues. Bei Jira kommen die geplanten Issues in einem Schritt in einen aktiven oder zukünftigen Sprint eines Boards.

Was gespeichert wird

Das Verbindungs-Token wird verschlüsselt auf dem Server gespeichert und erreicht nie den Browser. Beim Trennen wird es gelöscht. Details stehen in der Datenschutzerklärung.

Fragen

Ist die Jira-Integration kostenlos?

Ja. Jede Integration von Open Planning Poker ist kostenlos, auch der Import und das Zurückspeichern der Schätzungen.

Brauchen Spieler ein Jira-Konto?

Nein. Nur der Host verbindet Jira; die Spieler treten dem Raum über einen Link bei.
