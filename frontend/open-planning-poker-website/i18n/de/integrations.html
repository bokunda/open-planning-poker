Integrationen: Slack, Microsoft Teams und Jira

Open Planning Poker funktioniert dort, wo dein Team schon arbeitet. Jede Integration ist kostenlos und braucht kein Konto: Spieler treten weiterhin über einen Link bei.

Slack

Tippe /poker Sprint 43 in einen beliebigen Kanal. Open Planning Poker erstellt einen Raum und postet einen Join-Button. Nur du bekommst den Link, um das Spiel zu leiten. Nach jedem Aufdecken erscheinen das Ticket und seine Schätzung im Thread.

Zu Slack hinzufügen

Microsoft Teams

Füge Open Planning Poker als Tab in ein Meeting, einen Kanal oder einen Chat ein. Starte ein neues Spiel oder zeige ein vorhandenes. Alle stimmen im Tab ab, im Seitenbereich des Meetings oder auf der gemeinsamen Bühne.

Ein Teams-Admin lädt das App-Paket einmal im Teams Admin Center hoch. Das Paket open-planning-poker-teams.zip hängt an jedem Release auf GitHub.

Jira Cloud

Verbinde deine Jira-Site einmal im Import-Dialog. From Jira importiert die Issues eines Sprints, Boards oder einer JQL-Abfrage mit ihren Story Points. Nach dem Aufdecken schreibt Save to KEY die vereinbarte Schätzung in das Issue, auf Wunsch mit einem Kommentar mit den Stimmen und den Notizen der niedrigsten und höchsten Stimme.

GitHub, Linear und Azure DevOps

Derselbe Import und das Zurückspeichern funktionieren auch für GitHub Issues, Linear und Azure DevOps Boards. Schritt-für-Schritt-Seiten: Jira, GitHub, Linear und Azure DevOps.

Was gespeichert wird

  • Slack- und Jira-Tokens werden verschlüsselt auf dem Server gespeichert und erreichen nie den Browser. Beim Trennen von Jira werden seine Tokens gelöscht.
  • Teams braucht keine Tokens: Der Tab ist die normale Web-App innerhalb von Teams.
  • Details stehen in der Datenschutzerklärung.
